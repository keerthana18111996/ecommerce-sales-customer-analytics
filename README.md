# ecommerce-sales-customer-analytics
## project overview
This project analyzes e-commerce sales and customer data using python and pandas to identify sales trends, top products, customer behavior, payment methods and other business insights.
#Tools used
-python
-pandas
-matplotlib
## key Analysis
-Total orders and average order value
-sales by category and state
-monthly sales trends
-Top products by sales and quantity
-customer spending analysis
-payment method analysis
-discount analysis
