PROJECT OVERVIEW
This project analyzes e-commerce sales data to understand sales performance, product categories, customer purchasing patterns, and payment methods. The goal is to identify useful business insights from the dataset using data analysis techniques.

OBJECTIVES
Analyze overall sales performance.
Identify top-performing product categories.
Compare sales across different states.
Analyze payment method preferences.
Understand order quantities and discount patterns.
Generate insights to support business decision-making.

DATASET DESCRIPTION
The dataset contains 1,000 sample e-commerce orders generated using Python.
The dataset includes the following columns:
Order ID
Order Date
Category
Product
Sales Amount
Quantity
State
Payment Method
Discount

TOOLS AND TECHNOLOGIES
Python
Pandas
NumPy
Data Analysis
Exploratory Data Analysis (EDA)
Data Visualization (if used in the project)

ANALYSIS PERFORMED
Explored the dataset and checked its structure.
Analyzed sales by product category and state.
Compared payment methods used for orders.
Examined order quantities and discounts.
Identified sales trends and patterns in the sample data.

KEY FINDINGS
Karnataka recorded the highest sales among the states analyzed.
Tamil Nadu recorded the lowest sales among the states analyzed.
Payment method usage was compared to understand purchasing patterns.
